# `nfeio._generated`

Reservado para código gerado a partir das specs OpenAPI da NFE.io.

Regra: nada aqui é editado à mão. Se um arquivo gerado estiver errado, corrija o gerador ou a spec
(com o patch registrado) e gere de novo.

No v0.1 este diretório está vazio de propósito: os modelos são escritos à mão (visão tipada sobre o
dicionário do fio) e protegidos por um teste de alinhamento com a spec. Ver o design da change
`add-sdk-foundation-v0-1`, §12.
